### 3. Token 验证详情
**文件**: `internal/application/service/user.go`

```go
// 第323-354行：ValidateToken 方法
func (s *userService) ValidateToken(ctx context.Context, tokenString string) (*types.User, error) {
    // 1. 解析 JWT Token
    token, err := jwt.Parse(tokenString, func(token *jwt.Token) (interface{}, error) {
        return []byte(getJwtSecret()), nil
    })
    
    // 2. 验证 Token 有效性
    if err != nil || !token.Valid {
        return nil, errors.New("invalid token")
    }
    
    // 3. 提取 claims 中的 user_id
    claims, ok := token.Claims.(jwt.MapClaims)
    userID, ok := claims["user_id"].(string)
    
    // 4. 检查 Token 是否已被撤销（查询 auth_tokens 表）
    tokenRecord, err := s.tokenRepo.GetTokenByValue(ctx, tokenString)
    if err != nil || tokenRecord == nil || tokenRecord.IsRevoked {
        return nil, errors.New("token is revoked")
    }
    
    // 5. 从数据库获取用户信息
    return s.userRepo.GetUserByID(ctx, userID)
}
```

### 4. Handler 处理
**文件**: `internal/handler/auth.go`

```go
// 第265-295行：GetCurrentUser handler
func (h *AuthHandler) GetCurrentUser(c *gin.Context) {
    ctx := c.Request.Context()
    
    // 1. 从 context 获取当前用户（由 Auth 中间件注入）
    user, err := h.userService.GetCurrentUser(ctx)
    if err != nil {
        // 返回 401 错误
        appErr := errors.NewUnauthorizedError("Failed to get user information")
        c.Error(appErr)
        return
    }
    
    // 2. 获取租户信息（如果有）
    var tenant *types.Tenant
    if user.TenantID > 0 {
        tenant, err = h.tenantService.GetTenantByID(ctx, user.TenantID)
        // 即使获取失败也不中断请求
    }
    
    // 3. 转换为 UserInfo（去除敏感信息如 password_hash）
    userInfo := user.ToUserInfo()
    userInfo.CanAccessAllTenants = user.CanAccessAllTenants && h.configInfo.Tenant.EnableCrossTenantAccess
    
    // 4. 返回响应
    c.JSON(http.StatusOK, gin.H{
        "success": true,
        "data": gin.H{
            "user":   userInfo,
            "tenant": tenant,
        },
    })
}
```

### 7. 完整流程总结

```
1. 客户端发送请求
   GET /api/v1/auth/me
   Header: Authorization: Bearer <JWT_TOKEN>

2. Auth 中间件 (middleware.Auth)
   ├─ 提取 Bearer Token
   ├─ 调用 userService.ValidateToken()
   │  ├─ 解析 JWT Token
   │  ├─ 验证签名和有效期
   │  ├─ 从 claims 提取 user_id
   │  ├─ 查询 auth_tokens 表检查是否撤销
   │  └─ 从 users 表获取用户完整信息
   ├─ 获取租户信息（从 tenants 表）
   └─ 将 User 和 Tenant 存储到 Context

3. AuthHandler.GetCurrentUser
   ├─ 从 Context 获取 User（由中间件注入）
   ├─ 获取 Tenant 信息（可选）
   ├─ 转换为 UserInfo（去除敏感信息）
   └─ 返回 JSON 响应

4. 响应格式
   {
     "success": true,
     "data": {
       "user": {
         "id": "uuid",
         "username": "user1",
         "email": "user1@example.com",
         "avatar": "",
         "tenant_id": 10000,
         "is_active": true,
         "can_access_all_tenants": false,
         "created_at": "...",
         "updated_at": "..."
       },
       "tenant": {
         "id": 10000,
         "name": "user1's Workspace",
         ...
       }
     }
   }
```

### 8. 涉及的数据库表

1. **users** - 用户基本信息
2. **auth_tokens** - Token 存储和撤销状态
3. **tenants** - 租户信息

### 9. 安全机制

1. **JWT Token 验证**: 验证签名、有效期
2. **Token 撤销检查**: 查询数据库确认 Token 未被撤销
3. **密码保护**: 返回的 UserInfo 不包含 PasswordHash
4. **跨租户访问控制**: 需要 `CanAccessAllTenants` 权限和配置开启
5. **上下文隔离**: 通过 Context 传递认证信息，避免全局状态
