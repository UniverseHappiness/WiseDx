## 🔍 关键概念速览

### 什么是 knowledge-chat？
一个基于 RAG（检索增强生成）架构的知识库问答 API。用户提问 → 系统从知识库检索相关内容 → LLM 总结回答 → 流式返回结果。

### SSE 是什么？
Server-Sent Events，一种单向的服务器推送协议。允许服务器逐步发送数据，而不是一次性返回。这样用户能看到实时的答案流。

### Session 是什么？
一个对话会话。一个 session 中的多条消息会维持对话历史和上下文，实现多轮对话能力。

### Agent 是什么？
一个高级的参数配置包，可以绑定模型、系统提示词、知识库等。使用 agent 可以快速为不同场景（如医学、法律）定制不同行为。
